# Active research host

Use the application running this session. Claude Code loads `CLAUDE.md`,
Codex loads [AGENTS.md](../../../AGENTS.md), and Antigravity follows
[GEMINI.md](../../../GEMINI.md), including when it can also see AGENTS.md.
A request received over MCP is scoped to the assignment from the calling host.

For native tool names, delegation, user input and waiting, use the running
host's [Codex](../../../config/codex/host.md) or
[Antigravity](../../../config/antigravity/host.md) contract, or the Claude Code
instructions in the source skills. Use the shared [reviewer routing](reviewer-routing.md)
and [writing rules](writing-host.md) for every host.

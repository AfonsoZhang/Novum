# Citation Verification & Venue Selection

Apply the shared [working-language policy](../shared-references/research-autonomy.md#working-language) to internal work and user reports.

For publication status, version preference, and source verification rules, consult [publication-policy.md](../shared-references/publication-policy.md) and [citation-discipline.md](../shared-references/citation-discipline.md).

## Mode routing

Load only the module that matches the current task:

| Task | Module guide |
|---|---|
| Cross-check individual citations or complete bibliographies (authors, titles, years, volumes, pages, DOIs; Zotero corrections) | [modules/ref-verifier/GUIDE.md](modules/ref-verifier/GUIDE.md) |
| Build a ranked venue/track shortlist (topic fit, track fit, prestige signals, deadline proximity) with mandatory live CFP re-verification | [modules/select-venue/GUIDE.md](modules/select-venue/GUIDE.md) |

## Non-negotiable rules

- Never fabricate metadata, DOIs, page numbers, or citation entries; report unverified fields explicitly.
- Always re-verify venue deadlines, page limits, and track policies against the live CFP before relying on cached profiles.
